# Data Analyzer App

📊 **Анализатор опросов** с помощью Streamlit  

## 🚀 О проекте  
Приложение позволяет обрабатывать файлы формата SPSS, строить визуализации и таблицы сопряженности.  

👉 **Основные функции:**  
- Встроенная предобработка данных (удаление дубликатов, удаление служебных слов и символов)
- Автоматическое определение типа визуализации (гистограмма, круговая диаграмма, стобчатая диаграмма)
- Дополнительные типы визуализации, выбираемые вручную (диаграмма с группировкой, диаграмма с накоплением)
- Вывод таблицы сопряженности
- Проведение тестов для определения статистической значимости отличий фактических значений в таблице сопряженности от ожидаемых
- Настойка уровня значимости для проведения тестов
- Выбор поправок на множественное тестирование для автоматической корректировки уровня значимости (Холма, Бонферрони, Беньямини-Хохберга)
